# DJ Ronny Woods

Sitio de una sola página, en español, que presenta la trayectoria de DJ Ronny Woods en cuatro capítulos de scroll: el origen musical, la evolución como DJ, los viajes y escenarios, y la producción actual.

## Vista local

Abrí `index.html` en el navegador o levantá un servidor estático desde esta carpeta:

```bash
python -m http.server 8000
```

Luego visitá `http://localhost:8000`.

## Publicación

Los archivos están listos para servirse como sitio estático desde la raíz del repositorio. Las imágenes y el logo se cargan desde `assets/` con rutas relativas.
